# Contributing

Use Node.js 22+. Run `npm ci`, `npm run typecheck`, `npm test`, and `npm run build` in `mcp-server/` before proposing changes. Describe the issue, behavior change, and validation in pull requests. Use synthetic email metadata in tests and examples. Never commit personal vendor rules, bills, signed download links, credentials, or inbox data. Keep Gmail access in the host; accept only the selected bill metadata and temporary file links.

Contributions are accepted under the [MIT License](LICENSE).
