# Contributing

Use Node.js 22+. Run `npm ci`, `npm run typecheck`, and `npm run build` in `mcp-server/` before proposing changes. Describe the issue, behavior change, and validation in pull requests. Use synthetic email metadata in tests and examples. Never commit personal vendor rules, bills, signed download links, credentials, or inbox data. Keep Gmail access in the host and saving in the separate plugin.

Contributions are accepted under the [MIT License](LICENSE).
